# Contributing · 贡献指南

Thanks for your interest! 感谢参与！

## Ways to help · 参与方式

| What · 内容 | Where · 去哪里 |
|---|---|
| Ideas, new roles, rule changes · 想法、新角色、规则改动 | [Discussions](../../discussions) → *Ideas* |
| Answers to the PRD open questions · 回答 PRD 待讨论问题 | [Discussions](../../discussions) → *Q&A* |
| A concrete feature proposal · 具体的功能提案 | [Issues](../../issues/new/choose) → *Idea / Feature* |
| Bugs (once code exists) · 缺陷（有代码之后） | [Issues](../../issues/new/choose) → *Bug* |
| Code and docs · 代码与文档 | Pull request |

English or Chinese are both fine. 中英文都可以。

## Proposing a new role · 提议新角色

Please include · 请说明：

- Faction, starting resources, special action, win condition · 阵营、初始资源、特殊行动、胜利条件
- Why it makes the game more interesting · 为什么能让游戏更有趣
- How it could be abused, and how the referee would stop it · 可能怎样被滥用，裁判如何防止

## Pull requests

1. For anything bigger than a typo, open an issue or discussion first. 改动较大时，先开 Issue 或讨论。
2. Keep each PR focused on one thing. 一个 PR 只做一件事。
3. Never commit API keys or personal data. 不要提交 API Key 或个人数据。
4. By submitting a contribution, you agree it is licensed under the [Apache License 2.0](LICENSE). 提交贡献即表示你同意以 Apache License 2.0 授权。

## Ground rules · 基本规则

- Be respectful. No harassment, hate speech or personal attacks. 互相尊重，禁止骚扰、仇恨言论和人身攻击。
- Keep the game fictional. Proposals that involve real people, real locations, real money or real-world crime will be closed. 保持游戏虚构，涉及真实人物、真实位置、真实货币或现实犯罪的提议会被关闭。
- See the [disclaimer](DISCLAIMER.md). 另见[免责声明](DISCLAIMER.md)。
